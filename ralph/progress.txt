[2026-02-28 10:16:11] RALPH-GO: Description: # 📊 Dashboard de Productividad – Requerimientos

## 1️⃣ Objetivo General

Desarrollar un **dashboard centralizado** que permita visualizar la productividad del equipo utilizando información proveniente de:

- **Plane**
- **GitHub**

Toda la información debe almacenarse en una base de datos propia y poder sincronizarse manual o automáticamente.

---

# 2️⃣ Requerimientos – Plane

## 📌 Métricas de Productividad

Necesito visualizar:

- ¿Cuántas tareas (workitem) fueron terminadas?
- ¿Cuántas tareas están pendientes?
- ¿Cuántos puntos de Fibonacci se han trabajado? (Scrum)
- ¿Cuántos ciclos (sprints) van?
- ¿Cómo va el ciclo actual?
- Información de múltiples proyectos y múltiples ciclos activos al mismo tiempo.

La información debe poder verse:

- Por proyecto
- Por usuario
- En tablas simples
- En gráficas comparativas

---

## 📌 Comparativa entre miembros del equipo

Necesito poder comparar:

- Quién ha trabajado más tareas
- Quién ha completado más puntos
- Quién tiene tareas más complejas (según puntos Fibonacci)
- Quién tiene más carga activa
- Quién tiene más tareas atrasadas

---

## 📌 Gestión de Soporte

- Identificar qué proyectos están en soporte (a partir del intake en Plane).
- Los proyectos en desarrollo no tendrán esta opción.
- Mostrar:
  - Fecha de inicio del proyecto
  - Fecha fin del proyecto
  - Fecha de activación de soporte
  - Fecha final de soporte (21 días después del intake)

---

## 📌 Estado de tareas

Necesito saber:

- Cuántas tareas faltan
- Cuáles ya se terminaron
- Cuántas tareas tiene cada label
- El label bug
- Cuántos bug existen
- Cuántos atrasos hay por parte del cliente
- Cuántas tareas están pendientes por parte del cliente

---

# 3️⃣ Requerimientos – GitHub

También necesito sincronizar información de GitHub:

Por cada persona:

- Número de commits
- Número de Pull Requests
- Líneas nuevas escritas
- Líneas eliminadas
- Actividad por proyecto/repositorio

---

# 4️⃣ Sincronización de Datos

Toda la información debe guardarse en una base de datos propia.

## 🔄 Sincronización Manual

- Botón **“Sincronizar”**
- Al dar clic:
  - Mostrar una modal
  - Indicar progreso de sincronización
  - Traer toda la información desde Plane y GitHub
  - Actualizar el dashboard

## ⏰ Sincronización Automática

- Configurable desde la aplicación
- Poder elegir la hora exacta
- Que se ejecute automáticamente a esa hora

---

# 5️⃣ Integración Técnica

- Usar como base el repositorio de **https://github.com/Gebesa-Office-Furniture/neurya-hub** en GitHub (ya tiene sincronización funcional con Plane).
- Analizar cómo funciona la sincronización actual.
- Clonar la parte necesaria.
- Adaptarla al nuevo sistema.
- Diseñar correctamente la estructura de la base de datos.
- Definir tablas necesarias antes de implementar.

---

# 6️⃣ Visualización del Dashboard

Debe permitir:

- Tablas simples y claras
- Gráficas comparativas
- Filtros por:
  - Proyecto
  - Usuario
  - Ciclo
  - Fecha
  - Rango de fechas

---

# 🎯 Resultado Esperado

Un dashboard completo que permita:

- Medir productividad real del equipo
- Comparar desempeño entre miembros
- Monitorear soporte y proyectos activos
- Centralizar datos de Plane y GitHub
- Sincronizar datos manual o automáticamente
- Tomar decisiones con base en datos
